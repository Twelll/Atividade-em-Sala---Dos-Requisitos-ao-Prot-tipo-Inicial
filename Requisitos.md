# Requisitos Implementados no Protótipo

- **Requisito 1 (Funcional): Consulta de Vagas Disponíveis**
  - O sistema deve listar a contagem numérica de vagas por setor e exibir o status individual de cada vaga (disponível ou ocupada).
- **Requisito 2 (Funcional): Identificação de Vagas de Funcionários**
  - O sistema deve diferenciar visualmente vagas reservadas para funcionários no setor da biblioteca e permitir filtrar apenas vagas livres destinadas a estudantes.
