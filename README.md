# Protótipo CLI - Gestão de Vagas

Protótipo em linha de comando desenvolvido em Python para validação de requisitos de estacionamento.
Implementa o Requisito 1 (consulta numérica e status individual de vagas por setor) e o Requisito 2 (sinalização de vagas reservadas para funcionários e filtro de vagas livres para alunos).
Não requer dependências externas nem interfaces gráficas.

### Como Executar
```bash
python main.py
